# 项目介绍与技术选型
本项目为个人网站后端服务，qps较低，使用java+springboot的生态开发

# 主要依赖
* springboot使用3.5.x版本
* jdk使用jdk21
* 使用mybatis框架，添加PageHelper插件
* 使用redis
* 使用Spring Boot Actuator热更新配置
* jackson等工具依赖
* 使用maven管理，只在最外层进行统一管理，不在各模块中独立写pom.xml

# 模块划分
* flydeer-struct-mind-controller：独立的spring应用，负责与前端http交互，请求解析、鉴权解析、响应构造、cookie设置、处理异常
* flydeer-struct-mind-api：服务接口实现，与service的区别是面向业务，实现功能
* flydeer-struct-mind-contract：服务接口、请求体、响应体定义
* flydeer-struct-mind-service：服务接口的实现，与api区别是专注业务合理拆分，保证各服务逻辑合理、可用性、配置性等
* flydeer-struct-mind-repository：持久化层
* flydeer-struct-mind-common：公共类、工具类库
* flydeer-strcut-mind-task：独立的springboot应用，只需要依赖service、不需要依赖api，负责处理各种定时任务
